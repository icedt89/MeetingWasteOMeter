# 💸 Meeting Waste-o-Meter: Your Ultimate Cost Tracker! 💸

Tired of wondering just how much that long meeting is _really_ costing? Say hello to the **Meeting Waste-o-Meter** – your one-stop tool for calculating the real-time cost of any meeting, right from your browser! 🚀

Meeting Waste-o-Meter is a sleek, intuitive, and lightning-fast app that brings a little fun to tracking meeting expenses.

Visit [Meeting Waste-o-Meter](https://meetingwasteometer.jan-hafner.de) now!

## 🌟 Features You'll Love

- **Real-time Cost Tracking:** See the costs climb with every passing second! 💰
- **Dynamic Resource Management:** Add participants, set their hourly rates, and watch the total cost update instantly. 👥
- **Timer Controls:** Start, stop, and pause the calculation at any time. ⏯️
- **"Emoji Rain" Fun:** Make it rain emojis while the money counter goes up! 😂
- **Customizable Settings:** Set your preferred currency symbol and fine-tune the experience. ⚙️
- **Privacy Overlay:** Instantly hide sensitive information on the screen with a single click. 🔒
- **Installable App:** As a Progressive Web App (PWA), you can install it on your desktop or mobile for a native-app feel. 💻📱
- **Sleek & Modern UI:** Enjoy a beautiful, user-friendly interface built with Vuetify. 🎨

## 🚀 Why Choose Meeting Waste-o-Meter?

- **Raise Awareness:** Hilariously visualizes how quickly meeting costs can add up.
- **Always Available:** It's ready to go whenever you are, right from your browser or home screen.
- **Simple & Focused:** No complicated setup. Just add people, set rates, and press play.
- **Open Source:** The code is open for you to explore, customize, and contribute to!

## 💡 Get Started!

Using the Meeting Waste-o-Meter is a breeze. Just open the application, add your meeting participants as resources, and start the timer! ✨

## 🛠️ Tech Stack

- **Vue.js:** For a reactive and efficient user interface.
- **Vuetify:** A stunning Material Design component framework.
- **TypeScript:** For robust and scalable code.
- **Vite:** For a blazing-fast development and build experience.
- **Pinia:** For state management.
- **Vitest:** For unit testing.
